# chromatex

A maximalist, LaTeX-saturated single-page site with a dependency-free Rust backend.

Every formula on the page is LaTeX, typeset in the browser by KaTeX. Every formula
that is not a quotation is **computed in Rust** — exact rational power series,
fraction-free determinants, continued-fraction expansions — and shipped to the
browser as LaTeX source. The colour scheme is generated by the backend too.

## Run it

```sh
cargo run --release
# → http://127.0.0.1:8080
```

Options: `--host`, `--port`, `--static DIR`, `--workers N`, `--emit-static DIR`, `--help`.

## What the backend actually computes

| Module | What it does |
| --- | --- |
| `rational.rs` | Exact `i128` rationals with reduction, and LaTeX rendering that folds the variable into the numerator (`\frac{x^5}{120}`, not `\frac{1}{120}x^5`). |
| `series.rs` | Truncated power series over ℚ with Cauchy product and series division. `tan` and `sec` are **not** tables of Bernoulli numbers — they are `sin/cos` and `1/cos` evaluated by the division recurrence. |
| `matrix.rs` | Seeded integer matrices; determinants by **Bareiss elimination** (fraction-free, so it never leaves ℤ) and characteristic polynomials by Faddeev–LeVerrier. |
| `cfrac.rs` | The Euclidean algorithm on a real constant, rendered as a nested `\cfrac` tower, plus convergents and signed errors. |
| `palette.rs` | Colour schemes: hues advance by the golden angle (137.508°) from a seeded base, at full chroma, alternating luminance. Deliberately clashing. |
| `corpus.rs` | The curated theorem corpus and the short fragments used by the background layer. |
| `http.rs` | Blocking HTTP/1.1 on a fixed worker pool: request parsing, query decoding, traversal-safe static serving, I/O timeouts, header/body size caps. |
| `json.rs` | A small JSON writer. Hand-concatenating strings would eventually ship a response broken by an unescaped backslash, which with this much LaTeX is a certainty. |

### No dependencies

`Cargo.toml` has an empty `[dependencies]`. The whole backend is `std`: no
framework, no async runtime, no JSON crate. It builds with nothing but a Rust
toolchain and no network access. KaTeX is vendored under `static/vendor/`, so
the site has no CDN dependency either and works fully offline.

## API

Every endpoint returns LaTeX source.

| Route | Returns |
| --- | --- |
| `GET /api/health` | Liveness. |
| `GET /api/catalog` | Function ids, constant ids, and the server-side clamps. |
| `GET /api/series?f=<id>&n=<terms>` | A Taylor series with exact fractional coefficients. |
| `GET /api/matrix?n=<dim>&seed=<k>` | Matrix, determinant, trace, characteristic polynomial. |
| `GET /api/cfrac?c=<id>&n=<depth>` | `\cfrac` tower, bracket notation, convergents with error. |
| `GET /api/constants` | The constants available to `/api/cfrac`. |
| `GET /api/corpus?tag=<tag>` | The theorem corpus; the tag filter is optional. |
| `GET /api/drift` | Short fragments for the background layer and marquee. |
| `GET /api/palette?seed=<k>` | An eight-stop colour scheme. |

Out-of-range parameters are **clamped, not rejected** (`n=9999` gives the maximum
term count), and unparseable ones fall back to the default — a malformed query
string should not break the page. Unknown ids return `{"ok": false, "error": ...}`.

## The animation

Layered background (drifting multi-radial wash, crawling perspective grid,
canvas point-lattice, floating formulae, scanlines), a glitching chromatic-split
title, orbiting glyphs, an equation marquee, scroll-reveal panels, staggered
card entrances, rotating conic-gradient card rims, 3D tilt on hover, and a
cursor trail.

All of it is gated two ways:

- `prefers-reduced-motion: reduce` is honoured, including when the OS setting
  changes while the page is open.
- The `∂ₜ = 0` button in the header stops everything, including the canvas
  animation loop (which is also paused when the tab is hidden).

Colours live entirely in CSS custom properties written from the palette
endpoint, so recolouring the whole site is eight property writes.

## Deployment

GitHub Pages cannot run the backend, so the backend runs at build time instead:

```sh
cargo run --release -- --emit-static dist
```

This walks the full (finite) parameter space of the API and writes every
response to a file under `dist/data/`. It does so by building real `Request`
values and calling the same `routes::route` handler the live server uses, so an
exported file is byte-identical to what `GET`ting that URL would have returned —
there is no second implementation of the maths to drift out of sync.

The front end detects which deployment it is in by probing `data/static.json`,
then maps logical API URLs to exported files. Everything else in the code (and
everything the UI displays) still speaks in `/api/...` URLs. Paths are resolved
against `document.baseURI`, so the site works both at a domain root and at a
project subpath like `/AdvanceCaludeWebsite/`.

The one behavioural consequence: reroll seeds come from a bounded pool
(`routes::SEED_POOL`, currently `1..=128`) rather than being unbounded. **Both**
deployments use that same pool, so the hosted build cannot silently diverge from
the one you develop against.

`.github/workflows/pages.yml` runs the tests, builds the export, asserts the
tree is complete and contains no `"ok":false` payloads, and publishes to Pages
on every push to `main`.

## Tests

```sh
cargo test               # 61 unit tests
python3 scripts/smoke.py # end-to-end, needs firefox + geckodriver
```

`scripts/smoke.py` takes `CHROMATEX_URL`, so the same suite runs against the
live server, against the static export served by any plain file server, and
against the export mounted at a subpath — all three are verified.

The unit tests check the mathematics against known values rather than against
the implementation: `tan`'s coefficients to x⁹, `sec`'s to x⁶, π's continued
fraction yielding 22/7 and 355/113, φ's convergents being consecutive Fibonacci
numbers, the characteristic polynomial's constant term agreeing with the
determinant and its subleading coefficient with the trace across 40 seeds and
all five dimensions, JSON escaping of LaTeX backslashes, and that static path
resolution refuses to escape its root.

`scripts/smoke.py` drives headless Firefox over WebDriver and asserts that each
control actually changes the page, and that zero LaTeX fragments fail to typeset
after all the interaction.
