Taylor expansions, exactly

The backend holds truncated power series over and does real arithmetic on them. is not a table of Bernoulli numbers — it is evaluated by series division, every coefficient an exact fraction.

Determinants without rounding

Integer matrices from a seeded generator, reduced by Bareiss elimination — fraction-free, so the determinant stays in from start to finish. The characteristic polynomial comes from Faddeev–LeVerrier.

The colour scheme is also a function

Hues advance by the golden angle from a seeded base, at full chroma, alternating luminance. Deliberately clashing: a design system would never, which is the point.

The backend

Rust, std only — no crates, no async runtime, no framework. A blocking HTTP/1.1 server on a fixed worker pool. Every endpoint returns LaTeX source.
